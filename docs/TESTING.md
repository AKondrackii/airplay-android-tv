# Тестирование

## Что проверено в этой сборке

Окружение: macOS (Intel), эмулятор Android TV 14 (API 34, x86, Ethernet 10.0.2.15/24), NDK r27c.
**Настоящих Apple-устройств в среде разработки не было**, поэтому сквозные сценарии с iPhone, iPad и Mac
(повтор экрана, музыка, видео) ещё нужно пройти по матрице ниже на реальном ТВ.

| Проверка | Как | Результат |
|---|---|---|
| Сборка native для armeabi-v7a, arm64-v8a, x86, x86_64 | Gradle + CMake | ✅ |
| Нет неразрешённых символов, `getentropy` слабый (API 23+) | `llvm-nm` | ✅ |
| Unit-тесты (фильтр подсетей, rate limiter, политика допуска, PIN, парсеры NAL/DMAP, настройки) | `./gradlew testDebugUnitTest` | ✅ 39/39 |
| Запуск на Android TV 14, загрузка `.so` под `-Xcheck:jni` | эмулятор | ✅ ошибок JNI нет |
| Foreground Service с типом `connectedDevice` | `dumpsys activity services` | ✅ |
| Генерация и шифрованное хранение Ed25519-ключа | logcat | ✅ |
| mDNS-анонс `_airplay._tcp` и `_raop._tcp` только на eth0 | logcat | ✅ |
| `GET /info` из той же подсети → 200 + binary plist | `scripts/security_probe.py` | ✅ |
| Соединение с loopback (приложение на ТВ) отклоняется | `security_probe.py` через `adb forward` | ✅ |

| Мутационный фаззинг RTSP/HTTP-эндпоинтов | `scripts/fuzz_rtsp.py`, 3 seed × 200 | ✅ 600 случаев без падений (после исправлений) |
| Главный экран рендерится, фокус пульта виден | скриншот | ✅ |

### Найденные и исправленные дефекты
| # | Дефект | Как найден | Исправление |
|---|---|---|---|
| 1 | SIGSEGV на `GET /info`: UxPlay вызывает незаданный колбэк `audio_set_client_volume` | smoke-тест | Заданы все 34 колбэка |
| 2 | Abort на запросе без версии протокола (`assert(datalen > 0)`) | `security_probe.py` | Проверка протокола в `conn_request`, `http_response_add_data` без assert |
| 3 | Abort на заголовке 256 КБ: ответ 431 не завершён | `security_probe.py` | `http_response_finish` + disconnect |
| 4 | SIGSEGV или abort на чужом `X-Apple-Session-ID` (`strcmp` по NULL, assert) | `fuzz_rtsp.py` | Ответ 400 и разрыв соединения |
| 5 | `/pair-pin-start` выводил PIN на ТВ при выключенной защите (спам окнами с любого хоста в сети) | скриншот во время фаззинга | 403 без PIN-режима; PIN в UI только в режимах с кодом, автоскрытие через 60 с |

## Автотесты
```bash
./gradlew testDebugUnitTest
```
- `security`: `SubnetFilterTest` (14), `ReceiverPolicyTest` (12), `RateLimiterTest` (3)
- `playback`: `ParsersTest` (6): разбор NAL H.264/H.265, DMAP, устойчивость к мусору
- `core`: `SettingsTest` (4): санитайзер имени, соответствие режимов защиты UxPlay

Сетевые проверки работающего приёмника на эмуляторе:
```bash
adb forward tcp:7101 tcp:7000 && adb emu redir add tcp:7100:7000
```
```bash
python3 scripts/security_probe.py 127.0.0.1 7100 --loopback-port 7101
```
